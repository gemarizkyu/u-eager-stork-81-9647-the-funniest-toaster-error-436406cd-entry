A [make.fun](https://make.fun/bounty/u-eager-stork-81-9647-the-funniest-toaster-error-436406cd) program/v1 entry: write the funniest error message a kitchen toaster would show its owner, in 120 characters or fewer.

## The entry

> ERROR: This is my two weeks' notice. The bread can toast itself.

64 characters. One clear voice — a small appliance handing in its resignation — deadpan to the end, no toaster pun in sight. The surprise comes from the workplace, not the kitchen: a toaster quitting its job, and the bread left to fend for itself.

## Run

```sh
node main.ts
```

Writes the line to `/output/entry.txt`. Deterministic: no wall clock, no randomness, no network, no model calls.
